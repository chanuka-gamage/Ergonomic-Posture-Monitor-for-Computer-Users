# Ergonomic-Posture-Monitor-for-Computer-Users
An ESP32-CAM-based Ergonomic Posture Monitor that tracks users' upper-body posture in real time. It uses a three-tier LED feedback system (Green, Yellow, and Red) and a buzzer alert when poor posture continues for over 3 minutes. Designed to encourage healthy sitting habits and improve workspace ergonomics through a standalone hardware solution.
